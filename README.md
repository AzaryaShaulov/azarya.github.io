# Azarya Shaulov - sample portfolio

A responsive, dependency-free portfolio built with HTML and CSS. Open
[index.html](index.html) directly in a browser to preview it. No build step is
required; the root page can also be served by GitHub Pages when Pages is
configured to publish this branch from the repository root.

## Content

The sample uses the publicly visible introduction from
[LinkedIn](https://www.linkedin.com/in/azaryashaulov/) and the public
[GitHub profile](https://github.com/AzaryaShaulov/), including documentation for
the VM SKU Retirement Report and Azure repositories. LinkedIn exposes only a
partial profile without sign-in; the page does not infer a full employment
history, certifications, or customer results.

Project summaries and links are in [index.html](index.html); visual styles and
responsive layouts are in [styles.css](styles.css). The featured report graphic
is an illustration, not a live report. All project and contact links lead to
public GitHub or LinkedIn pages.
